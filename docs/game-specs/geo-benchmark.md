# Geo Benchmark MVP 게임 규칙

확정일: 2026-09-06. 상태: 3단계 브라우저 MVP 구현 및 로컬 검증 완료.

## 플레이와 입력
- 브라우저에서 총 5라운드를 진행하며 매 라운드 거리/도시 사진 1장을 표시한다.
- 모델 응답은 수동 입력한다. 세계 지도 클릭으로 추측 좌표를 선택한다.
- 국가와 도시는 각각 “모름”을 허용한다.
- 확신도(0~100%)와 추론 근거는 필수이다. 0%는 유효하며 미입력과 구분한다. 공백만 있는 근거는 허용하지 않는다.

## 데이터셋
- 외부 Street View API 없이 고정 이미지와 JSON 장소 데이터를 사용한다.
- 재배포 가능한 실제 사진 25장을 선정하고 출처, 라이선스 및 촬영 좌표를 검증한다.
- 사진 풀은 쉬움 5장 / 보통 15장 / 어려움 5장이다. 게임마다 1라운드 쉬움 1장, 2~4라운드 보통 3장, 5라운드 어려움 1장을 무작위로 뽑는다. 한 게임 내 사진은 중복되지 않는다.
- 도시 중심점이나 랜드마크 좌표를 촬영 좌표로 대신하지 않는다.
- 이미지 경로, 국가/도시, 위도/경도, 난이도, 출처, 저작자, 라이선스, 촬영 좌표 근거와 데이터셋 버전을 기록한다.
- 실제 사진 25장 선정과 출처 기반 촬영 좌표 검증을 완료했다. 검증 근거와 정확도 한계는 [데이터셋 보고서](../datasets/geo-benchmark-v2.md)에 기록한다.

## 점수와 공개
- 실제 좌표와 추측 좌표의 거리에 따라 라운드당 0~5000점, 총 25000점으로 채점한다.
- 감쇠 상수는 2000km이다. 계획의 계산식은 round(5000 * exp(-distanceKm / 2000))이며 Haversine 거리 계산을 사용한다.
- 라운드 점수는 제출 즉시 표시한다.
- 실제 위치와 정답은 5라운드 종료 후 공개한다. 중간 화면에 정답 국가/도시, 실제 좌표, 정답 마커와 연결선을 표시하지 않는다.
- 최종 화면에는 라운드별 결과와 총점을 표시한다.
- 국가/도시/확신도/근거는 기록하며 거리 점수에 가산하지 않는다.

## 검증 기준
- 5라운드 완주, 중복 제출 방지, 정답 공개 시점, 난이도 구성과 입력 검증을 확인한다.
- 동일 좌표, 날짜 변경선, 극지방, 대척점, 잘못된 좌표와 거리 증가에 따른 점수 비증가를 검증한다.
- 한영 UI와 키보드 접근성을 제공한다.
- 로그인, DB, 백엔드와 자동 모델 API 호출은 MVP 범위에 포함하지 않는다.
- 정적 앱의 정답 데이터는 개발자 도구에서 확인 가능하다. 공개 시점은 화면 규칙이며 비공개 시험 보안 기능은 아니다.

실행 계획: [MVP 계획](../plans/2026-09-05-geo-benchmark-mvp.md).

## 3단계 구현 (2026-09-06)
- `/games/geo-benchmark`에 한영 UI, 로컬 지도 클릭/확대/이동/방향키, 좌표 직접 입력을 제공한다.
- 필수 입력, 즉시 점수, 5회 종료 후 정답/출처, 재시작과 결과 JSON 다운로드를 구현했다.
- 상태는 메모리에서만 유지하며 새로고침 시 초기화한다.

## 상세 지도 개선 (2026-09-06)
- 기본 지도 화면은 Leaflet 1.9.4와 Esri World Street Map 타일을 사용해 최대 19단계까지 도시·도로·건물을 영어 지명 우선으로 표시한다.
- 클릭으로 추측 선택, 드래그/방향키로 이동, Enter로 지도 중심 선택, 확대/축소 버튼과 좌표 직접 입력을 지원한다.
- 상세 지도는 인터넷 연결이 필요하며 타일 실패 시 안내한다. 기존 Natural Earth 기본 지도로 전환 가능하다.
- 실제 위치 마커는 기존과 동일하게 5라운드 완료 후에만 표시한다.

## 지도 조작 개선 (2026-09-06)
- 제출 전 선택 해제 버튼으로 마커와 위도/경도 입력을 함께 초기화한다. 다른 응답 필드는 유지한다.
- 상세/기본 지도 모두 확대·축소 버튼과 마우스 휠은 현재 화면 중심을 기준으로 동작한다.
- 상세 지도 더블클릭과 핀치 확대도 화면 중심을 사용한다.

## 무작위 출제와 재현
- 시작과 다시 시작에서 새로운 추첨을 수행한다. 서로 다른 게임에서는 같은 사진이 다시 나올 수 있다.
- 선택한 5장은 해당 게임 동안 고정되며 지도 조작, 입력, 언어 변경으로 다시 뽑지 않는다.
- 최종 JSON에 추첨 알고리즘 버전, 시드, 선택한 사진 ID 순서를 기록한다. 완료 전에는 시드와 미래 사진 ID를 공개하지 않는다.
- 기존 채점 방식과 실제 위치/출처 공개 시점은 유지한다.
