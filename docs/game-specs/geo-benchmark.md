# Geo Benchmark MVP 게임 규칙

확정일: 2026-09-06. 상태: 1단계 순수 엔진 구현 완료. 실제 사진과 UI는 후속 단계.

## 플레이와 입력
- 브라우저에서 총 5라운드를 진행하며 매 라운드 거리/도시 사진 1장을 표시한다.
- 모델 응답은 수동 입력한다. 세계 지도 클릭으로 추측 좌표를 선택한다.
- 국가와 도시는 각각 “모름”을 허용한다.
- 확신도(0~100%)와 추론 근거는 필수이다. 0%는 유효하며 미입력과 구분한다. 공백만 있는 근거는 허용하지 않는다.

## 데이터셋
- 외부 Street View API 없이 고정 이미지와 JSON 장소 데이터를 사용한다.
- 재배포 가능한 실제 사진 5장을 선정하고 출처, 라이선스 및 촬영 좌표를 검증한다.
- 난이도는 쉬움 1장 / 보통 3장 / 어려움 1장이다. 이는 구성 비율이며 순서는 별도 계획 항목이다.
- 도시 중심점이나 랜드마크 좌표를 촬영 좌표로 대신하지 않는다.
- 이미지 경로, 국가/도시, 위도/경도, 난이도, 출처, 저작자, 라이선스, 촬영 좌표 근거와 데이터셋 버전을 기록한다.
- 실제 이미지 선정과 검증은 아직 완료되지 않았다.

## 점수와 공개
- 실제 좌표와 추측 좌표의 거리에 따라 라운드당 0~5000점, 총 25000점으로 채점한다.
- 감쇠 상수는 2000km이다. 계획의 계산식은 round(5000 * exp(-distanceKm / 2000))이며 Haversine 거리 계산을 사용한다.
- 라운드 점수는 제출 즉시 표시한다.
- 실제 위치와 정답은 5라운드 종료 후 공개한다. 중간 화면에 정답 국가/도시, 실제 좌표, 정답 마커와 연결선을 표시하지 않는다.
- 최종 화면에는 라운드별 결과와 총점을 표시한다.
- 국가/도시/확신도/근거는 기록하며 거리 점수에 가산하지 않는다.

## 검증 기준
- 5라운드 완주, 중복 제출 방지, 정답 공개 시점, 난이도 구성과 입력 검증을 확인한다.
- 동일 좌표, 날짜 변경선, 극지방, 대척점, 잘못된 좌표와 거리 증가에 따른 점수 비증가를 검증한다.
- 한영 UI와 키보드 접근성을 제공한다.
- 로그인, DB, 백엔드와 자동 모델 API 호출은 MVP 범위에 포함하지 않는다.
- 정적 앱의 정답 데이터는 개발자 도구에서 확인 가능하다. 공개 시점은 화면 규칙이며 비공개 시험 보안 기능은 아니다.
