# 이미지 기반 위치 추론 벤치마크 MVP 계획

상태: 2026-09-06 사용자 결정 반영 완료. 문서 접근 확인 완료. 2단계 실제 사진 데이터셋 연결 완료; UI는 후속 단계. 코드 통합과 정적 배포 호환성은 구현 전에 검증한다.

## 확정된 요구사항

- 브라우저에서 실행하는 데스크톱 우선 앱. 로그인, DB, 백엔드, 외부 Street View API 없이 고정 이미지와 JSON 데이터셋을 사용한다.
- 총 5라운드, 라운드마다 거리 또는 도시 사진 1장을 표시한다.
- 세계 지도 클릭으로 추측 좌표를 선택한다.
- 실제 좌표와 추측 좌표 사이 거리를 계산하고 라운드마다 0~5000점을 부여한다. 최종 만점은 25000점이다.
- 국가명, 도시명, 확신도 0~100%, 추론 근거 입력 영역을 제공한다.
- 라운드 점수와 최종 총점을 표시한다.
- 저장소 지침에 따라 한국어/영어 메시지, 키보드 조작, 가시적 포커스, 44px 이상 터치 타깃을 제공한다.

## 권장 구현안 — 아직 제품 결정으로 확정하지 않음

- 기존 Next.js App Router와 TypeScript를 재사용하고 클라이언트에서 게임을 실행한다. 정적 내보내기 호환성을 확인한다.
- 기능을 src/features/geo-benchmark/ 아래 순수 채점 엔진, 데이터 검증, UI, 결과 내보내기로 분리한다. 라우트와 게임 목록 등록은 기존 구조 확인 후 정한다.
- 지도는 로컬 세계 지리 데이터 기반 SVG로 제공하고 확대/축소, 이동, 마커 선택을 구현한다. 지도 출처 및 라이선스를 기록한다. 좌표 직접 입력을 키보드 대안으로 제공한다.
- 화면은 상단 진행률, 왼쪽 큰 사진, 오른쪽 지도, 하단 응답 폼과 제출 버튼으로 구성한다.
- 제출 전 마커를 수정할 수 있고 제출 후 응답을 잠근다. 좌표 미선택, 잘못된 좌표, 확신도 범위 오류를 검증한다.
- Haversine 공식으로 km 단위 대원 거리를 계산한다. 제안 채점식은 round(5000 * exp(-distanceKm / 2000))이며 0~5000으로 제한한다. 상수와 수식은 버전 관리한다. 국가/도시/확신도/근거는 기록만 하고 점수에 반영하지 않는다.
- 같은 데이터셋 버전과 고정 순서를 모든 실행에 사용해 비교 가능성을 확보한다.
- 선택 입력으로 모델명/버전, 프롬프트, 실행 메모를 남기고 결과 JSON 다운로드를 제공한다. API 자동 호출 없이 사용자가 모델 응답을 옮겨 적는 수동 벤치마크로 시작한다(사용자 확정).
- 초기 버전은 메모리 상태로 실행하며 새로고침 시 초기화됨을 안내한다. 저장 복구가 필요하면 버전과 모든 필드를 검증하는 별도 어댑터를 추가한다.

## 데이터셋

- datasetVersion, id, imagePath, latitude, longitude, country(ko/en), city(ko/en), sourceUrl, author, license, coordinateSource, difficulty를 관리한다.
- 재배포 가능한 실제 사진 5장을 확보하고 사진 촬영 위치를 검증한다. 도시 중심 좌표를 촬영 좌표로 대신 사용하지 않는다.
- 파일명/대체 텍스트에 정답을 넣지 않고 EXIF 위치 메타데이터를 제거한다. 필요한 사진 크레딧은 결과 화면에서 제공하되 라이선스 조건을 따른다.
- 좌표 범위, 중복 ID, 필수 필드, 이미지 누락을 검증한다.
- 정적 앱의 정답 JSON은 개발자 도구로 확인할 수 있다. 화면 기반 자율 평가용이며 비공개 정답을 보장하는 시험 시스템은 아니다.

## 2026-09-06 사용자 확정 사항

1. 모델 응답은 수동 입력으로 시작한다.
2. 재배포 가능한 사진 5장을 선정하고 출처 및 촬영 좌표를 검증한다. 쉬움 1장 / 보통 3장 / 어려움 1장으로 구성한다.
3. 채점 감쇠 상수는 2000km이다. 라운드 점수는 즉시 표시하며 실제 위치와 정답은 5라운드 종료 후 공개한다.
4. 국가와 도시는 “모름”을 허용하고 확신도(0~100%)와 추론 근거는 필수이다.

확정 규칙: [Geo Benchmark](../game-specs/geo-benchmark.md).

## 완료 기준

- 고정된 5개 장소를 끝까지 플레이하고 각 점수와 총점을 확인할 수 있다.
- 동일 좌표 0km/5000점, 날짜 변경선, 극지방, 대척점, 좌표 범위, NaN, 거리 증가에 따른 점수 비증가를 검증한다.
- 중복 제출과 라운드 건너뛰기를 방지하고 누락 이미지/잘못된 JSON은 명확한 오류로 처리한다.
- 동일 입력과 데이터셋/채점 버전에서 동일 결과가 나온다.
- 다운로드한 결과에 5개 응답, 추측/정답 좌표, 거리, 점수, 총점, 데이터셋/채점 버전이 포함된다.
- 정적 빌드에서 실행 가능하고 Street View/API 키/DB 없이 핵심 기능이 동작한다.
